# Java 后端知识点学习路线

## 1. 使用说明

这组文档把苍穹外卖项目拆成一个个可以独立学习的知识单元。每篇文档都围绕四个问题展开：

1. 这个知识点解决什么问题？
2. 当前项目中哪些代码实现了它？
3. 一次请求经过哪些对象和框架？
4. 代码中还有哪些边界或可以改进的地方？

建议按编号顺序学习。编号不是文件创建时间，而是按照后端知识之间的依赖关系排列的：先理解项目和 Spring，再理解 HTTP 和数据访问，最后学习安全、缓存、第三方服务和工程化。

补充专题：[Spring 注解分类与项目实战](09-spring-annotations/00-注解分类总览.md)。该专题把容器、Web、异常、事务、缓存、AOP 和任务注解集中对照，适合在阅读具体模块时查阅。

## 3. 推荐学习方法

每读一篇文档，最好在 IDE 中完成一次代码追踪：

```text
找到 URL
  -> 找到 Controller 方法
  -> 找到 Service 接口和实现
  -> 找到 Mapper 方法
  -> 找到 XML 或注解 SQL
  -> 找到对应 Entity 和数据库字段
  -> 观察响应如何回到客户端
```

读完后可以尝试修改一个小需求，例如给分类增加查询条件、给订单增加状态校验或给菜品缓存增加过期时间。真正理解的标准不是记住注解名称，而是能解释每一层为什么存在，以及删除某一层会造成什么影响。
