# 26 微信小程序登录

## 1. 登录模型

小程序登录通常不是把用户密码直接交给业务服务器，而是由小程序获取临时 `code`，后端拿 `code` 调微信接口换取 OpenID，再建立自己的登录会话。

## 2. 项目中的代码

入口：[`UserController.java`](../../../sky-server/src/main/java/com/sky/controller/user/UserController.java)

```java
@PostMapping("/login")
public Result<UserLoginVO> login(
        @RequestBody UserLoginDTO dto) {
    User user = userService.wxLogin(dto);
    // 将 user.getId() 放入 JWT
    return Result.success(userLoginVO);
}
```

业务实现：[`UserServiceImpl.java`](../../../sky-server/src/main/java/com/sky/service/impl/UserServiceImpl.java)

```text
接收 code
  -> 调用微信 jscode2session
  -> 获得 openid
  -> 按 openid 查询用户
  -> 不存在则创建用户
  -> 返回用户并签发本项目 JWT
```

## 3. OpenID 和本地用户 ID

OpenID 是微信体系中的用户标识，本项目仍然为用户建立自己的 `user.id`，并把本地 ID 放入 JWT。这样业务表只依赖本地用户主键，降低对第三方身份格式的耦合。

## 4. 学习重点

- 临时 `code` 有时效且只能使用一次。
- 微信接口调用失败、OpenID 缺失和用户创建失败都应分别处理。
- 不要把 `appSecret` 暴露给小程序前端。
- 本地 JWT 与微信登录凭证是两种不同的身份材料。

## 5. 学习练习

模拟微信接口返回错误码，设计重试和错误提示；再为 `openid` 增加唯一约束，思考并发首次登录时如何避免重复创建用户。
