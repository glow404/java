# 28 第三方 HTTP 服务调用

## 1. 为什么要封装远程调用

业务代码不应到处手写 HTTP 客户端、请求头和响应解析。统一的 HTTP 工具可以集中处理连接、参数、响应和异常。

## 2. 项目中的工具

代码位置：[`HttpClientUtil.java`](../../../sky-common/src/main/java/com/sky/utils/HttpClientUtil.java)

它提供 GET、POST 等方法，微信登录和百度地图调用都通过它发起远程请求。

## 3. 百度地图案例

订单 Service 在校验配送范围时：

```text
店铺地址 -> 百度地理编码接口 -> 店铺坐标
用户地址 -> 百度地理编码接口 -> 用户坐标
两点坐标 -> 路线规划接口 -> 驾车距离
距离超过范围 -> 抛出业务异常
```

相关逻辑位于 [`OrderServiceImpl.java`](../../../sky-server/src/main/java/com/sky/service/impl/OrderServiceImpl.java)，地图 Key 通过 `sky.baidu.ak` 配置。

## 4. 远程调用的工程要点

- 设置连接超时、读取超时和整体超时。
- 处理网络失败、HTTP 非 2xx、第三方错误码和响应字段缺失。
- 对可重试请求设置有限次数和退避，不能无限重试。
- 不要把完整请求参数、密钥或用户隐私写入日志。
- 第三方服务不可用时，应明确是拒绝下单、降级还是异步补偿。

## 5. 学习练习

为地图调用增加超时和错误码判断，并把第三方响应转换为内部结果对象，避免业务层直接依赖第三方 JSON 结构。
