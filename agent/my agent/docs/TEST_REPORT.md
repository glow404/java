# 第一版实施与测试报告

执行日期：2026-10-08，Windows / Docker Desktop Linux 容器。首次第一版验收使用 disabled/mock；用户补充云渡配置后，当前本地服务已切换 `MODEL_PROVIDER=openai_responses`，监听 `127.0.0.1:8080`。本报告区分初次界面/持久性验收、适配器自动化替身与后续真实云渡联调。

## 实现范围

新增 React/TypeScript/Vite/Ant Design/ECharts 工作台及独立 FastAPI 后端，PostgreSQL JSONB 动态数据、Alembic 迁移、Argon2 密码及服务端 Cookie 会话、逐资源账号校验、Redis/RQ 解析和导出、LangGraph PostgreSQL 检查点、严格模型适配器、查询结果快照与一次性事务变更。Docker Compose 的数据库、队列、上传目录有持久卷，PostgreSQL 不映射宿主端口。

原目录没有可复用前端、应用测试或 Worker/D1；用户确认新增第一版。未发布生产、修改共享权限、提交或推送 Git，也未清空数据库或持久卷。其他上级未跟踪项目未修改。旧 D1 只提供可审阅迁移方案。

## 后端用例覆盖

- 两个账号与匿名请求：表、文件、任务、会话、消息、结果、计划、操作历史、源文件和导出下载归属；拒绝自报身份、越权资源、错误 CSRF 与过期会话，检查 HttpOnly/SameSite Cookie 和登出失效。
- 实际 PostgreSQL 过滤、排序、分组、平均值、独立分母占比、单位不匹配与范围越界；缺少占比阈值/分母先澄清，后续文本补充可形成计划。结果与消息共用唯一 ID。
- 新增/修改/删除预览、确认、取消、过期、表版本冲突、范围变化、另一登录会话、重复确认和并发确认；注入审计失败验证数据、结果、计划、审计完整回滚。删除保留删除前快照，修改仅展示受影响记录。
- 工作流在业务提交与检查点写入之间重放时复用原结果/计划；新的 graph/数据库连接可恢复真实持久检查点中的确认中断。
- RQ 任务真实 Redis 状态、文件路径/大小/哈希与账号核对；解析失败重试、队列不可用、失去 worker 恢复、重试不重复创建表、按版本导出和越权下载拒绝。
- 导入 450 行的窗口与远端行修正、互斥表头候选、汇总表关联与唯一粒度、元数据版本与类型转换、改写原文不得继续标成文件原文、已确认推断类型不能冒充原文类型。
- 模型适配使用 `httpx.MockTransport`，覆盖禁用与协议许可门槛、generic JSON 映射、无效结构化输出、SQL/代码/额外属性拒绝、HTTP 限流与服务错误、超时/网络/协议错误、响应大小和并发上限。它只验证适配逻辑，不能证明真实服务商支持该协议。

## 验证中发现并修复

真实 PostgreSQL 分组暴露 JSON 字段绑定参数不一致，已复用 SELECT 表达式并回归；RQ 阻塞消费不能使用 API 短超时，已分离连接超时；管理员初始化引用错误变量，已修复并让账号测试使用同一创建入口；Nginx 保留 Host 端口以匹配 Origin。API 地址变化后的代理旧 IP 导致502，已使用 Docker DNS 动态解析；前端健康检查同时访问 API 就绪端点。机制依据 [Nginx 官方 proxy_pass 文档](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_pass) 和 [Compose 网络说明](https://docs.docker.com/compose/how-tos/networking/)。浏览器脚本修正图标/中文按钮定位，并为每轮表名添加唯一后缀以保留既有测试数据；恢复脚本修正 Python 模块路径、PowerShell UTF-8 BOM/数组参数和 TestClient Cookie 作用域。

上述修复后已重新通过对应验证。另补充来源标注回归：后续编辑不能把用户说明或已确认推断类型改标为文件原文；数据库确认在 FastAPI 同步线程池中运行，避免事务阻塞事件循环。`scripts/start.ps1` 已在当前环境实际执行并等待全部服务健康。首次 `/api/ready` 返回 ready/disabled；后续云渡配置部署后返回 ready/openai_responses。

## 仍需配置或人工验收

**真实云渡端点已验证**：用户后来提供端点、协议、模型和密钥；实际模型目录及 Responses 调用证据见 [云渡联调记录](RELAY_VERIFICATION.md)。严格计划校验、超时、429、网络失败、拒答及工具输出的故障测试仍是 MockTransport，不能视为真实服务故障验收。正常管理员账号由部署者交互创建，不提供公开默认密码。

正式内网部署仍需公司 HTTPS 域名/证书或反向代理、`COOKIE_SECURE=true` 与明确的 `TRUSTED_ORIGINS`。本次只验证本机 HTTP 容器，未部署到公司的真实网络，也未做生产负载/渗透测试。复杂跨页/扫描表、未知身份和不确定结构仍须人工整理核对；旧 xls 需转换。当前查询计划以单表为执行单位，分粒度表保存关联元数据，跨表连接查询不在第一版计划语法中。前端历史快照全量恢复适合第一版规模，超大量会话需进一步分页优化；大 bundle 性能提示尚存。
