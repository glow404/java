# 现有 Cloudflare Worker / D1 演示的迁移审阅方案

本目录未发现 Worker/D1，第一版后端独立运行，没有删除、替换或访问任何线上演示。

如需后续迁移，先提交以下材料供审阅，获得针对该演示的迁移授权后再执行：

1. 在演示所属环境导出 D1 数据、结构、Worker 版本和配置；加密保存快照，记录导出时间与校验哈希。导出命令需根据实际 Wrangler 版本及数据库标识核实。
2. 创建明确的旧用户 → 新账号映射，不能把没有 owner 的数据授予任意新账号。孤立记录进入待核对清单。
3. 在独立 PostgreSQL 数据库导入。保留源主键、文件引用、来源及迁移批次，映射到已登记逻辑字段 ID；按真实粒度区分汇总与明细。
4. 对比账号数、表数、行数、空值、标识前导零、关键汇总、文件哈希、权限和抽样查询。形成差异清单，不以单一行数代替校验。
5. 先让旧演示保持可用，新后端只在隔离环境验收。确定切换窗口、写入冻结/增量同步策略和负责人员。
6. 回滚使用保留的旧演示版本和只读导出。出现差异立即撤回新入口，不覆盖原 D1；新产生的数据另行导出并审阅合并。

持久卷不是备份。任何线上导出、映射、切换或删除都不包含在此次本地新增版本的授权范围内。
