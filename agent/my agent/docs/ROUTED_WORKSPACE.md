# 路由工作台（2026-10-12）

中间内容拆为独立页面，左侧菜单和右侧 Agent 在路由切换中保持挂载。

- `/`：当前账号活动表数量、表名及说明、创建/导入/管理入口、已登记关联规则。
- `/tables` 和 `/tables/:id`：完整记录每页20条、表资料编辑、精确单行变更、导出、关联管理和最近变更摘要。
- `/conversations/:id`：当前对话快照；最近对话选项展示最后一次用户提问，按最近消息活动排序。
- `/profile`：昵称、简介、邮箱、头像和密码。登录用户名保持固定；邮箱是唯一登录别名，变更需当前密码，本期没有验证码邮件或邮箱找回密码。

React Router 是本次新增依赖。Nginx SPA 回退支持直接访问及刷新详情网址。切页保留草稿和运行状态；刷新后的草稿持久化不在本次范围。

## 数据操作

记录编辑发送实际 `row_id` 和打开草稿时的版本，服务器预览/确认精确单行，重复业务编号不会扩大修改范围。数字0和空值分别保留。最近变更先在服务器按表过滤，再排序和限制数量。

永久删除清理表、记录、双侧关联、相关结果/历史计划、助手响应、LangGraph检查点、导出和候选预览，保留对话文字及无原始数据的删除摘要。共享源文件继续供其他活动或归档表使用，最后一个引用消失时再删除；共享原文件可能仍包含被删逻辑表的原始内容。

相关文件任务或助手正在工作时返回409，需先中止/完成再预览。常规操作使用账号共享锁，删除获取独占锁；工作流采用可重入会话锁，避免删除后旧检查点写回。SQL与检查点共享事务；磁盘文件在提交后清理，失败明确返回503，可重复确认继续清理。
